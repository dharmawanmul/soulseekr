Connect Your Spotify

Because this app is 100% serverless and hosted on GitHub Pages, it uses official Spotify PKCE OAuth (no client secret or backend server required!).

Need a free Client ID?
1. Open Spotify Developer Dashboard and click Create an App.
2. In your app settings, add these Redirect URIs (tip: add all 3 so you can log in anywhere!):
http://127.0.0.1:5173/
http://localhost:5173/
https://dharmawanmul.github.io/soulseekr/
3. Select Web API under APIs, click Save, then paste your Client ID above!
